# Acknowledgements

## Cloud Map Imagery

This application uses near real-time cloud imagery provided by [Matt Eason](https://clouds.matteason.co.uk/).
Images are updated every 3 hours and derived from EUMETSAT satellite data.
The cloud texture is used in equirectangular projection with alpha transparency.

- Cloud image URL: [https://clouds.matteason.co.uk/images/4096x2048/clouds-alpha.png](https://clouds.matteason.co.uk/images/4096x2048/clouds-alpha.png)
- Source: [clouds.matteason.co.uk](https://clouds.matteason.co.uk/)
- License: [CC0 1.0 Universal (Public Domain)](https://creativecommons.org/publicdomain/zero/1.0/)
- Attribution:
  **Contains modified EUMETSAT data**
  The base Earth imagery is provided by NASA and is in the public domain.

Special thanks to [Matt Eason](https://twitter.com/MattEason) for maintaining the cloud data service.

**NASA GIBS (Global Imagery Browse Services)**
VIIRS Corrected Reflectance (TrueColor) imagery is provided by NASA EOSDIS through the GIBS platform.
[https://earthdata.nasa.gov/gibs](https://earthdata.nasa.gov/gibs)
