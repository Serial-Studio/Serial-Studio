Это бесплатная версия Serial Studio Pro: все основные функции
доступны бесплатно и без ограничения по времени. Перечисленные ниже
функции Pro разблокируются, как только вы попробуете любую из них,
с бесплатным 14-дневным пробным периодом. Для его начала не требуются
ни учётная запись, ни оплата.

Бесплатна для личного, учебного и open-source использования;
для коммерческого использования требуется лицензия Pro.

→ Поддержка: alex@serial-studio.com
→ Запланировать звонок: https://calendly.com/serial-studio
→ Узнать больше: https://serial-studio.com/

Доступные функции Pro:
→ Визуализация MQTT и 3D
→ Драйверы Audio, CAN Bus, Modbus, USB, HID и Process I/O
→ Виджеты вывода, экспорт MDF4 и передача XMODEM/YMODEM/ZMODEM
→ Historian, Переменные и преобразования (JS + Lua)
→ Мультиисточниковые проекты и настраиваемые рабочие пространства
