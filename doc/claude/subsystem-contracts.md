# Subsystem Contracts — Read Before Touching

Each row is a trigger, not a summary: read the named section before editing that area.
The hazard column names what breaks silently; the doc holds the rule.

| Touching | Read | Hazard |
|----------|------|--------|
| Any `ProjectModel` mutator, undo/redo (spec 0031) | [project.md](architecture/project.md) "Undo History" | Mementos are two-phase: `ProjectUndoScope` stages, the first `setModified(true)` commits — omit it and nothing is recorded. Enforced: code-verify:undo-scope-missing. |
| A dataset property or any API-surface generator (specs 0036, 0037) | [project.md](architecture/project.md) "Dataset Property Registry", `project.md` "Generated API Surfaces" | `app/rcc/properties/dataset.json` generates six checked-in artifacts — **never hand-edit a generated file**. gRPC field numbers are append-only; a moved one fails CI. |
| A toolbar button, palette entry, context menu, shortcut, or fixed icon (specs 0028/0063) | [commands-icons.md](architecture/commands-icons.md) "Icons", `commands-icons.md` "Commands" | Icons resolve ONLY via `Misc::IconRegistry` — never hardcode `qrc:/icons/...`. New command = one manifest entry + one bindings entry; Enforced: script:scripts/registry-verify.py. Project Editor context menus are registry-driven too (`editor-menus.json` + `ProjectEditorMenuBindings.qml` + `CommandMenu.qml`) — never hand-write a `Menu` there. |
| Installable widgets, `UI::WidgetExtensions` (spec 0038) | [dashboard.md](architecture/dashboard.md) "Widget Extensions" | Packages resolve to `DashboardExtension = 100`, persist as `"ext:<id>"`; `readsStringValues` is what registers one in `string_targets`. Trust model is consent, not containment — never call an extension sandboxed. |
| Alarm bands: `UI::AlarmMonitor` trackers, the annunciator's band points, the Project Editor's Alarm Bands buttons, the `suppressAlarms` or `alarmsWhileVisible` option (specs 0093/0105) | [dashboard.md](architecture/dashboard.md) "Alarm Bands" | Whether a dataset's bands are drawn has ONE home, `SerialStudio::datasetRendersAlarmBands`, and whether they alarm one more beside it (`datasetRaisesBandAlarms`, `datasetAlarmsNow`). A second copy of one lets a band drawn nowhere sound while the editor refuses to open it. |
| `core/Ui/Console/Annotations.*`, `ConsoleAnnotations.qml` (spec 0059) | [dashboard.md](architecture/dashboard.md) "Frame annotation layer" | `annotate()` stages, `commitPending()` publishes per tick — reading `count()` right after needs a commit. `reset()` clears the model *before* re-reading the offset. |
| `core/Api/API/Mirror/`, `streamAvailable()` (spec 0040) | [mirror.md](architecture/mirror.md) "Wire protocol" | Dataset ordering or `wireUniqueId` changes are wire breaks: bump `kWireVersion`, regenerate `tests/fixtures/mirror/`. Viewer frames never reach the export fan-out. |
| Chrome motion: a popup, menu, dialog or button animation in `app/qml` | [PopupEnter.qml](../../app/qml/Widgets/PopupEnter.qml), [PopupExit.qml](../../app/qml/Widgets/PopupExit.qml) | Popups take the two shared transitions plus a `transformOrigin`, never an ad-hoc `Transition`. Anything that scales, slides or bounces gates on `Cpp_Misc_GraphicsBackend.reduceMotion` (fades stay). Animate `opacity`/`scale`/`Translate` only — never `width`/`height` of a laid-out item, never inside `Widgets/Dashboard/` or a recycled `TreeView`/`ListView` delegate. |
| HDR output: `HdrSurface`/`HdrBoost`, `Misc::HdrOutput`, an emissive material, a shader under `app/shaders/`, or any `MultiEffect`/`layer` near an emissive element (spec 0089) | [dashboard.md](architecture/dashboard.md) "HDR Output" | The whole UI composites SDR inside a per-window FP16 layer; only the output transform converts. An emissive element behind a `MultiEffect` or default-format layer silently clamps to SDR. `_qt_sg_hdr_format` is private Qt API — re-verify per Qt bump. |
| An embedded code editor's render cadence | [scripting.md](architecture/scripting.md) "Embedded Code Editors" | Never give a main-window-embedded editor an unconditional per-tick `grab()` — cost 13% of the GUI thread (2026-08-17). |
| The AI assistant: a tool tier, the checkpoint timer, a provider, the tool surface, the sandbox roots | [ai.md](architecture/ai.md) "The Tier Model", `ai.md` "Checkpoint Semantics" | A mutating tool call takes a **checkpoint**, never a save. Every command sits in exactly one tier of `command_safety.json`; an unlisted name silently falls through to `Confirm`. Enforced: ctest:tst_command_safety_table. The bundled source behind the `source/` prefix (spec 0078) is read-only and joins a search ONLY through the `path` scope — never add it to the default walk. |
| Locating a god object's concerns (`ProjectModel`, `ProjectHandler`, `FrameBuilder`, `Dashboard`) | [directory-map.md](directory-map.md) | Spec 0070 re-formed the god objects into facades owning real sub-object classes (one class = one .h/.cpp, in a sibling dir named after the facade). Never split one class across TUs: decompose into member sub-objects instead. |
| The connect gate, a dataset transform or user-table mutator, or any new way to author either (spec 0094) | [io.md](architecture/io.md) "Opening a Link" | A project with transforms or user tables refuses to CONNECT unlicensed (`IO::EntitlementGate`, rule in `SerialStudio::proContentSummary`), and a live unlicensed session ends when its content grows past what its connect admitted. A new authoring path (API command, importer, generator) needs the license refusal too. |
| Anything that switches the operation mode: a project load, save or generation, a file drop, an example download, the Project Editor opening (spec 0100) | [AppState.h](../../core/Pipeline/AppState.h) | An *implicit* switch goes through `AppState::requestOperationMode()`, which defers while a link is live and applies on disconnect; only explicit mode choices (radios, `mode.*`, CLI, the API mode command) call `setOperationMode()`. A direct `setOperationMode` from a load path rebuilds devices under a live connection. |
| A new API command, one that runs or installs code, loads a project or launches a process, or one that re-dispatches other commands (spec 0098) | [CommandCapabilities.h](../../core/Api/API/CommandCapabilities.h), [CommandRegistry.h](../../core/Api/API/CommandRegistry.h), [LaunchAuthorizer.h](../../core/Core/IO/LaunchAuthorizer.h) | Every command carries a capability classification, and the remote gate refuses one without. Enforced: ctest:tst_command_capability_registry. Dry runs and compile checks build their engines with `ScriptSurface::Inert`, never the live bridges. Every program start, a script's `system.exec` or a Process source, asks `IO::authorizeLaunch` (the per-project launch consent). Remote origin is a dispatch scope (`RemoteDispatchScope`), never a per-site check, and the assistant's tiers ride a separate `DispatchPolicyScope`, because licensing reads `RemoteDispatchScope::active()`. `SERIAL_STUDIO_API_AUTO_CONSENT=1` grants every gate for headless runs. |
| A new API command, or anything that serializes the project or a live frame outward (spec 0096) | [io.md](architecture/io.md) "Sealed Sessions" | A process opened from a `.ssdeploy` package is sealed one-way (`Core::Runtime::sealed()`). A new command needs a classification in `API::SealedPolicy`, and an unclassified name is refused (Enforced: ctest:tst_sealed_policy_registry). A new exit for the project or a live frame consults the seal and strips through `DataModel::stripSealedContent`, or it hands the package's script source to any API client (Enforced: ctest:tst_sealed_strip). |
| Anything under `core/` or a source that could move there (spec 0076) | [directory-map.md](directory-map.md) "core/" | A library never includes `app/src`; a moved `Q_OBJECT` header listed in both a library and the executable mocs twice; every `.h`/`.cpp` pair lives in one target; a relative include must resolve in exactly one root; an upward include beyond `scripts/layer-baseline.json` fails CI; the bus is never on the per-frame path. |
| The driving surface (spec 0101): `core/Ui/UI/Automation/`, `AutomationHandler`, an `objectName` under `app/qml`, or the `DrivesUi` consent | [automation.md](architecture/automation.md) | A control is addressed by its `objectName` and nothing else: a translated or theme-derived name breaks every client, an unnamed control is invisible, and click/key sit behind a consent no other consent unlocks. Roles lean on Qt internal class names pinned by `tst_ui_automation`; re-verify per Qt bump. |
| Quick Plot parsing: `LineFormat`, `QuickPlotFormatState`, `QuickPlotBuilder`, `line_values`, Save as Project (spec 0106) | [dataflow.md](architecture/dataflow.md) "The Quick Plot Lane" | ONE tokenizer serves the live lane and the saved project; a second splitter diverges them. Detection runs once per connect, never during replay or audio; missing or text fields are NaN, skipped by every ring. |
| A `#ss` declaration, `declaration.json`, a `wire` flag or `firmware/` (spec 0111) | [dataflow.md](architecture/dataflow.md) "Device Declarations" | Keys are generated into the app and three libraries; a hand-typed key list drifts silently. The prefix test runs before 0106 detection, or a declaration establishes a format. |
