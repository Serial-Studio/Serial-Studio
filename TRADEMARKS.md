# Serial Studio Trademark Policy

"Serial Studio", the Serial Studio logo, and the project's trade dress are
trademarks of Alex Spataru, in continuous use in commerce since 2020. They are
claimed as unregistered (common-law) marks. This policy is separate from the
software licenses: the GPL and commercial licenses grant copyright permissions
only, and neither grants any trademark rights.

This policy exists so users can tell official Serial Studio software from
third-party builds. It does not limit any right granted by the GPL to use,
modify, or redistribute the code.

## Uses that need no permission

- **Nominative use.** Referring to Serial Studio by name to identify it —
  in articles, documentation, tutorials, package descriptions, comparisons,
  academic work, or statements such as "compatible with Serial Studio" or
  "based on Serial Studio source code".
- **Unmodified redistribution.** Distributing unmodified GPL builds or the
  unmodified source under the project name, with a statement that the package
  is community-built and not provided or supported by the Serial Studio project.
- **Linking** to serial-studio.com or the official repository.

## Uses that need permission

- Using the Serial Studio name, logo, or trade dress as the name or branding of
  a **modified** build that is distributed to others.
- Naming a fork, product, service, or company "Serial Studio" or something
  confusingly similar.
- Using the logo in a way that implies endorsement, affiliation, or official
  status.

## Distributed modified builds

If you distribute a modified build (as the GPL entitles you to), you must:

- Rename it — do not call the application "Serial Studio" and do not ship the
  official logo or icons as its branding.
- You may state, in text, that it is derived from Serial Studio and link to the
  official repository. This is nominative use and is welcome.

Private, undistributed modified builds are unaffected by this policy.

## Third-party GPL packages

Package maintainers who compile GPL builds from source may use the name
"Serial Studio" to identify the package. Label it as a community-built GPL
version, state that it excludes Pro features, and state that it is not
supported by the official project. Do not use the official logo as the
package icon without permission.

## Official binaries

Packages that redistribute the official precompiled binaries are distributing
proprietary software under the EULA and must not describe it as GPL or
open-source software.
